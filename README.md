# แผนผังเส้นทางถนนและอาคาร มหาวิทยาลัยเกษตรศาสตร์ (บางเขน)
> แผนผังแผนที่เวกเตอร์ 2.5D แสดงผังเส้นทางถนน ประตูทางเข้า-ออก และอาคารสำคัญ สำหรับนิสิต ผู้ค้า/ตั้งร้าน และการเดินทางสัญจร

---

## 🌟 จุดเด่นของระบบ

1. **แสดงโครงข่ายถนนและอาคารสำคัญ**:
   - แผนผังถนนสายหลักใน มก. (ถนนชูชาติ กำภู, ถนนสารสนเทศ, ถนนจักรพันธ์, ถนนจันทรสถิตย์)
   - เชื่อมต่อประตูทางเข้า-ออกรอบรั้วมหาวิทยาลัย: ประตูวิภาวดี, ประตูงามวงศ์วาน (1, 2, 3), ประตูพหลโยธิน และสถานี BTS มหาวิทยาลัยเกษตรศาสตร์
2. **อาคารสำคัญที่จำเป็น**:
   - สระพระพิรุณ, หอประชุมใหญ่, สำนักหอสมุด (อาคารสารนิเทศ 50 ปี), สำนักบริการคอมพิวเตอร์ (OCS), สนามกีฬาอินทรีจันทรสถิตย์, ศูนย์เรียนรวม 3, โรงอาหารบาร์ใหม่, โรงเรียนสาธิตเกษตรฯ, โรงพยาบาลสัตว์ มก.
   - อาคารจอดรถ: วิภาวดีรังสิต, งามวงศ์วาน 1, งามวงศ์วาน 2
3. **เปิด Google Maps นำทางตรงได้ทันที**:
   - แตะที่อาคารหรือประตูบนแผนที่ เพื่อดูชื่อ ข้อมูลสังเขป และกดเปิด Google Maps พิกัดจริงได้ในคลิกเดียว (รองรับ Universal Deep Link ป้องกัน In-App Browser ค้าง)
4. **ลื่นไหล 60fps บนมือถือและคอมพิวเตอร์**:
   - แผนที่ SVG เวกเตอร์ ไม่ใช้ไลบรารีหนัก
   - รองรับ Pinch-to-zoom, Drag-to-pan, Wheel zoom และปุ่มควบคุมมุมมอง
