# ระบบแผนที่และตรวจสอบที่จอดรถสด งานลอยกระทง ม.เกษตรศาสตร์ (บางเขน)
> ออกแบบเฉพาะสำหรับงานลอยกระทง โดยคัดกรองเฉพาะ 3 อาคารที่ได้รับอนุญาต: **งามวงศ์วาน 1, งามวงศ์วาน 2 และ วิภาวดี**

---

## 🌟 จุดเด่นของระบบนี้ (แก้ปัญหาจาก kuparking เดิม)

1. **อิสระ 100% ไม่ต้องพึ่ง Server หรือ API ของ มก.**: 
   - สามารถโฮสต์ขึ้น Vercel / GitHub Pages / Netlify ได้ฟรี 0 บาทใน 1 นาที
2. **เฉพาะ 3 อาคารที่ได้รับอนุญาตจริง**:
   - ปิดการแสดงผลอาคารบางเขน หรืออาคารอื่นๆ นอกพื้นที่จัดงาน เพื่อป้องกันคนขับหลง
   - แสดงระยะเวลาเดินจากอาคารจอดรถไปยัง **สระพระพิรุณ (จุดลอยกระทง)**
3. **ระบบสลับสถานะสำหรับสต๊าฟหน้างาน (`admin.html`)**:
   - สต๊าฟหรือ รปภ. ประจำแต่ละอาคารสามารถเปิดผ่านมือถือเพื่อกด `[ว่าง]` `[ใกล้เต็ม]` `[เต็ม]` หรือกด `[-10]` `[+10]` ได้ใน 2 วินาที
   - มีระบบล็อกรหัส PIN ป้องกันคนนอกกด (PIN เริ่มต้น: `1234`)
4. **Interactive Mobile Map**:
   - ใช้ภาพแผนที่ Isometric ลิขสิทธิ์ของ มก. แต่เสริมระบบ **Pinch-to-zoom และ Drag-to-pan** ให้เลื่อนซูมดูบนมือถือได้ลื่นไหล 60fps
   - มีหมุดระบุจุดสำคัญ: จุดลอยกระทงหลัก, ตลาดของกิน/เวที, ห้องน้ำ, ประตูเข้า-ออก
   - **คลิกนำทางด้วย Google Maps ได้ทันที** ในคลิกเดียว

## 🚀 วิธีการทดสอบใช้งานบนเครื่อง

1. ดับเบิ้ลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Safari, Edge)
2. เปิดอีกแท็บหนึ่งเป็น `admin.html` (ใส่ PIN: `1234`)
3. เมื่อสต๊าฟกดปรับตัวเลขหรือสถานะในหน้า `admin.html` หน้า `index.html` จะอัปเดตแบบเรียลไทม์ทันที!

### วิธีที่ง่ายที่สุด: Vercel หรือ Netlify (ฟรี 100%)
1. สมัครบัญชีฟรีที่ [vercel.com](https://vercel.com) หรือ [netlify.com](https://netlify.com)
2. ลากโฟลเดอร์ `ku-loykrathong-parking` ไปวาง (Drop to deploy)
3. จะได้ URL ทันที: `https://kuloykrathong.vercel.app`
4. นำลิงก์นี้ไปแปลงเป็น QR Code แปะตามป้ายไวนิลหน้าทางเข้าประตู หรือแชร์ลงเพจงานและไลน์กลุ่มได้ทันที!
