# Knowledge Registry & Harness² Post-Flight Reflection

| What | Why | How | Scope |
| :--- | :--- | :--- | :--- |
| **Interactive 3D Perspective Map Mode without WebGL overhead** | Users desire an Apple/Google Maps-like 3D tilt and gyro feeling while retaining ultra-fast, zero-dependency, single-screen mobile responsiveness. | Use CSS 3D Transforms (`perspective: 1200px`, `transform-style: preserve-3d`) combined with subtle mouse/touch parallax (`rotateX`, `rotateZ`) on an SVG/DOM board, bypassing heavy Three.js/MapboxGL libraries. | Web Maps / Event UI |
| **Integrity of Realtime Parking Telemetry** | Displaying fabricated/mock remaining slot numbers confuses drivers and damages trust during live events. | Completely eliminate mock numbers; display verified official structural capacity (~289, ~192, ~150 slots) alongside true live operational status (Open/Warning/Full) controlled directly by field staff. | Telemetry / Event Ops |
| **Bilingual Thai-Latin Typography & 44px Touch Targets** | Mixed script rendering often leads to diacritic clipping and poor touch ergonomics on mobile devices during festive navigation. | Enforce Latin-first pairing ("Inter" before "Prompt"), zero letter-spacing for Thai, line-height >= 1.35 for UI controls, and HIG 44px touch bounding boxes separated from visual surfaces. | UI/UX & Design |
| **Hand-Drawn Sketch to Precision Vector Cartography Alignment** | Translating human hand-drawn sketches (yellow roads, red parking structures, blue pond zones) to digital web maps requires mathematical preservation of topological relations. | Structure SVG viewBox to 1600x1000, model upper & lower horizontal spines, feeder vertical gates, and align interactive DOM hotspot pins via dynamic aspect-ratio container binding (`fitMapToViewport`). | GIS / Cartography / Frontend |
| **BTS Elevated Viaduct Skytrain Simulation & Interactive Docking** | Simulating an urban transit line along a perimeter highway adds rich contextual realism and direct navigational guidance for mass transit commuters. | Implement a 4-car EMU model inside an aligned SVG overlay using GPU-accelerated RAF transforms (`translate3d`), with smooth cubic ease-out deceleration into the station, passenger dwell timing, and interactive hover/touch summoning that parks the train and displays connection skybridge guidance to campus gates. | Animation / Urban Transit UI / Interactive Maps |
| **QGIS GIS-Grounded Vertical Reflection Pool & Complete Campus Arterial Grid** | Discrepancies between digital vector maps and physical campus geography (such as mistaking rectangular reservoirs for circular ponds) create cognitive dissonance for users cross-referencing official maps. | Extract real GIS coordinates and layer topologies (QGIS `.gpkg`/`.shp`), rendering water bodies with authentic aspect ratios (vertical rectangular pool `80x140` in front of Grand Auditorium) and complete arterial avenues connecting perimeter highway gates into continuous circulation loops. | Cartography / Spatial UI |
| **Official Google Maps Deep Linking & Exact Ground Coordinates** | Inaccurate map URLs or rough approximation coordinates cause drivers to be directed to wrong campus gates. | Bind official Google Maps short links (`maps.app.goo.gl`) directly in `PARKING_CONFIG` and `EVENT_CONFIG` with fallback merging in `openParkingModal`, ensuring navigation buttons and clipboard actions always launch official destination pins. | Telemetry / Navigation / Event Ops |
| **SVG Meet-Mode Letterbox Offset Compensation** | Fixed attribute dimensions (`width="1600" height="1000"`) without `w-full h-full` cause SVG containers in portrait mobile screens to stretch DOM height, inducing vertical letterbox offsets (>50px) that throw off programmatic auto-centering. | Apply `w-full h-full max-w-full max-h-full` to `<svg>` and calculate true render scale using `Math.min(vw / 1600, vh / 1000)` along with exact meet-mode letterbox offsets `(vh - 1000 * scale) / 2` when computing pan translation coordinates. | Mobile Cartography / SVG ViewBox |
| **Two-Finger Pan Translation & Pinch Focal Pivot Stability** | Naive gesture handlers subtract moving focal points or fail to capture initial touch deltas, deadlocking translation or causing anchor point drift during two-finger interactions. | Store `initialFocalX/Y` and `initialPanX/Y` on touchstart; on touchmove apply translation offset $(\text{currFocal} - \text{initFocal})$ alongside scale adjustment anchored strictly to `initialFocal`, seamlessly falling back to single-finger drag on finger lift without jumping. | Touch Gestures / Canvas & SVG Pan-Zoom |
| **Mobile Map Viewport Maximization via Collapsible Bottom Sheet** | Fixed footers (~180px) consume >45% of vertical mobile screens, severely hindering map exploration in crowded outdoor festivals. | Implement an ergonomics-first collapsible bottom sheet (~56px peek header, 90.2% map screen ratio) supporting tap toggle and touch drag/swipe with gesture conflict guard (`sheetHasSwiped`) to prevent synthetic click bounce. | Mobile UX / Festival Ops |
| **In-App Browser Intent Bypass for Navigation (LINE/Facebook)** | Embedded in-app webviews swallow short URLs or fail to open native Google/Apple Maps, stranding drivers inside web frames. | Standardize destination intents to `https://www.google.com/maps/dir/?api=1&destination=LAT,LNG`, triggering OS-level intent disambiguation to native navigation apps across Android and iOS. | Mobile Navigation / Deep Linking |
