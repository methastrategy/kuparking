# Knowledge Registry & Harness² Post-Flight Reflection

| What | Why | How | Scope |
| :--- | :--- | :--- | :--- |
| **Interactive 3D Perspective Map Mode without WebGL overhead** | Users desire an Apple/Google Maps-like 3D tilt and gyro feeling while retaining ultra-fast, zero-dependency, single-screen mobile responsiveness. | Use CSS 3D Transforms (`perspective: 1200px`, `transform-style: preserve-3d`) combined with subtle mouse/touch parallax (`rotateX`, `rotateZ`) on an SVG/DOM board, bypassing heavy Three.js/MapboxGL libraries. | Web Maps / Event UI |
| **Integrity of Realtime Parking Telemetry** | Displaying fabricated/mock remaining slot numbers confuses drivers and damages trust during live events. | Completely eliminate mock numbers; display verified official structural capacity (~289, ~192, ~150 slots) alongside true live operational status (Open/Warning/Full) controlled directly by field staff. | Telemetry / Event Ops |
| **Bilingual Thai-Latin Typography & 44px Touch Targets** | Mixed script rendering often leads to diacritic clipping and poor touch ergonomics on mobile devices during festive navigation. | Enforce Latin-first pairing ("Inter" before "Prompt"), zero letter-spacing for Thai, line-height >= 1.35 for UI controls, and HIG 44px touch bounding boxes separated from visual surfaces. | UI/UX & Design |
| **Hand-Drawn Sketch to Precision Vector Cartography Alignment** | Translating human hand-drawn sketches (yellow roads, red parking structures, blue pond zones) to digital web maps requires mathematical preservation of topological relations. | Structure SVG viewBox to 1600x1000, model upper & lower horizontal spines, feeder vertical gates, and align interactive DOM hotspot pins via dynamic aspect-ratio container binding (`fitMapToViewport`). | GIS / Cartography / Frontend |
